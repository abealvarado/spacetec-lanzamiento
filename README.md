# SPACE TEC — Landing page
Sitio estático listo para GitHub Pages.

## Publicar
1. Crea un repositorio en GitHub.
2. Sube **el contenido de esta carpeta** a la raíz del repositorio (index.html, styles.css, script.js y assets/).
3. En GitHub abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige la rama `main` y la carpeta `/ (root)`, luego **Save**.

## Personalizar
- `index.html`: textos, integrantes, resultados y contenido del proyecto.
- `styles.css`: diseño y colores.
- `assets/`: logos e imágenes.
