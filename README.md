# SPACE TEC — Entrega final

Landing page estática preparada para GitHub Pages.

## Publicar
1. Crea un repositorio en GitHub.
2. Sube **todo el contenido de esta carpeta** a la raíz del repositorio (no subas la carpeta contenedora).
3. Ve a **Settings → Pages**.
4. En *Build and deployment*, selecciona **Deploy from a branch**.
5. Elige `main` y `/ (root)` y guarda.

## Estructura
- `index.html`
- `styles.css`
- `script.js`
- `assets/` — logos y fotografías
- `.nojekyll`

## Contador
La fecha está fijada en `script.js` como `2026-12-02T07:00:00-07:00`, por lo que representa explícitamente las 7:00 a. m. UTC−7.

## Nota sobre Rocket Tec Sinaloa
El archivo `assets/rocket-tec-sinaloa.svg` es un identificador gráfico local creado para esta entrega porque no se proporcionó el archivo del logotipo oficial. Si recibes el logo oficial, puedes reemplazar ese archivo manteniendo el mismo nombre, o cambiar su ruta en `index.html`.
